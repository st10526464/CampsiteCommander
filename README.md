# CampsiteCommander
The Campsite Commander Android app is built in Kotlin with Android Studio. It helps users store and organize camping gear and food supplies. The app opens with a splash screen that shows the app name for 3 seconds before switching to the main screen. On the main screen, users can add new gear and see the total number of items packed. This total is calculated by a loop that adds up all the quantities in a parallel array. The app uses parallel arrays to keep track of item names, categories, quantities, and notes, with each index representing a complete gear entry. Users can go to an “Add Gear” screen to enter new items, and the data gets added to the arrays with the “+=” operator. A detailed view screen shows the full checklist by looping through the arrays and displaying each item with its category, quantity, and notes. Navigation between screens uses Intents, and a back button lets users return to the main screen. Overall, the app shows how to use arrays, loops, user input, and screen navigation to manage a simple inventory system.
